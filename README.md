# Power BI Practice

A collection of Power BI dashboards, reports, and practice projects focused on data analysis, data modeling, DAX, and interactive visualization.

## About This Repository

This repository contains my hands-on Power BI practice work. I use real-world-style datasets to practice cleaning data, building data models, writing DAX measures, and designing interactive dashboards.

## Topics Covered

- Power BI Desktop basics
- Importing and connecting data sources
- Power Query for data cleaning and transformation
- Data modeling and relationships
- Star schema concepts
- DAX measures and calculated columns
- Data visualization and report design
- Interactive filters, slicers, and drill-through
- Dashboard design and storytelling
- Publishing reports to Power BI Service

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
- CSV / Excel datasets
- SQL, where required

## How to Open the Reports

1. Download the required `.pbix` file from the project folder.
2. Open it using Microsoft Power BI Desktop.
3. If a dataset is required, place it in the same folder or update the data source path.
4. Explore the report using slicers, filters, and visuals.
